## If the website is blocked

Every project folder above includes a written walkthrough and screenshot that can be reviewed entirely on GitHub. No demo-site connection is needed to read them.

For interactive local review, download the demo pack, unzip it, and follow its `START-HERE.md`. It contains the same browser applications and fictional sample data. A local web server is needed for browser modules and workbook resources; simply double-clicking the HTML file will not load every feature. The pack includes a dependency-free Node launcher, plus a Python alternative.

## What this showcase contains

This repository contains review materials and a built browser demo pack. It does not publish the private development repositories, server-side tracking keys, live databases or borrower information. HBF Intel is clearly identified as a development-stage brief. Collateral Control is a self-contained demonstration of the existing calculation engine and synthetic portfolio, not a connected production environment.

CoStar branding is illustrative, used only to show how the tools could look. These are independent work samples by Rohail Abid; no affiliation or endorsement is implied.
